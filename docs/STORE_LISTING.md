## Name

GFGHub

## Short description (≤ 132 chars)

Auto-sync your accepted GeeksforGeeks solutions to your own GitHub repo —
organized, deduped, zero copy-paste.

## Detailed description

GFGHub quietly backs up every GeeksforGeeks problem you solve to a GitHub
repository you control.

- **Automatic** — the moment a submission is accepted, your solution is
  committed. No copy-paste.
- **One-click GitHub connect** — sign in with GitHub's official device flow. No
  personal access tokens to paste, no passwords, no backend.
- **Organized** — solutions land under `<Category>/<problem-slug>/solution.<ext>`,
  the category derived from the problem's topic tags.
- **Readable** — each problem gets a README, and your repo's main README keeps an
  auto-maintained index of everything you've solved.
- **Private by default** — create a new private repo from the popup, or point
  GFGHub at an existing one.
- **Yours only** — everything runs in your browser and talks only to GitHub. No
  servers, no analytics, no tracking.

## Single purpose

GFGHub has one purpose: to save a user's own accepted GeeksforGeeks solutions to
their own GitHub repository.

## Permission justifications

| Permission | Why |
|---|---|
| storage | Store the GitHub token, chosen repo, and local sync history in the browser. |
| scripting | Read the full solution from the problem page's code editor on an accepted verdict. |
| alarms | Reliably retry a failed sync after the MV3 service worker goes idle. |
| notifications | Notify the user of sync success or a problem that needs attention. |
| geeksforgeeks.org host access | Detect accepted submissions and read the solution/metadata. |
| api.github.com + github.com host access | Authenticate and commit files to the user's repository. |

## Icon

Generated by `npm run icons` (`scripts/gen-icons.mjs`) — a pure-Node script that
draws the badge and writes `public/icon-{16,48,128}.png`. No SVG source and no
external rasterizer (rsvg/ImageMagick) are needed; the script is the icon's
source of truth. `npm run build` copies the PNGs into `dist/`. To change the
icon, edit the design constants at the top of `scripts/gen-icons.mjs` and re-run.
